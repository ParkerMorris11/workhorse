Detail 06 / From the workshop

School OS: the method, applied to my own semester.

School OS is a system I built for my BYU courses. A Cloudflare Worker syncs Canvas and my lecture notes into a D1 database, and the same authenticated API serves a React dashboard, a Tauri desktop app, and ChatGPT over MCP. It has read-only access to Canvas, and submissions stay manual.

Cloudflare Workers + D1. A cron-triggered SyncService runs every 30 minutes through a queue, one run per course, with 3 retries.
Auth on every request. Auth0 issues RS256 JWTs, and the router verifies each one with jose against the JWKS.
Snapshot publishing. Each sync writes a full run, then flips published_run, so readers never see a half-finished sync.
