# Workhorse

Static site for Workhorse: practical AI systems for repeated work.

Served by GitHub Pages from the root of `main`. There's no build step: edit `index.html` and push.

| File | Purpose |
|---|---|
| `index.html` | The whole page (inline CSS, Google Fonts) |
| `school-os-architecture.png` | School OS architecture diagram used on the page |
| `school-os-diagram.png` | Plain-language version of the diagram (not linked from the page) |
| `workhorse-lockup-ink.png`, `workhorse-mark-ink.png` | Logo assets |
| `favicon.png`, `og-image.png` | Tab icon and link-preview image |

Before launch: the final "Book a workflow teardown" button in `index.html` still points to `#`. Search for "Replace href".
